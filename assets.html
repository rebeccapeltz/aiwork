MAC Agent 18.5 MB Download app_mac
Instructions
  • Download app_mac
  • Create a directory ~/Documents/KnowledgeAssistant
  • Copy app_mac into directory
  • Open Terminal (press Cmd+Space, type "Terminal", press "Return)
  • Go to folder ~/Docments/KnowledgeAssistant: cd ~/Documents/KnowledgeAssistant
  • Make file runnable by typing: chmod +x app_mac
  • Remove download block by typing: xattr -d com.apple.quarantine app_mac
  • If the command says "no such xattr", that's OK it means the block wasn't there
  • Start the app by typing: ./app_mac
Windows Agent 18.4 MB Download app_windows
Instructions
  • Download app_windows
  • Create a directory c:\Users\\Documents/KnowledgeAssistant
  • Copy app_windows into directory above
  • Double click the file
  • If you see "Windows protected your PC" click "More info", then "Run anyway"
  • If your browser warns that the file isn't commonly downloaded, choose Keep in the download menu
  • Your browser should open to the app immediately
